Runtime secret policy: .env is intentionally excluded; create it from .env.example when customization is needed.
Frontend runtime policy: vanilla HTML/CSS/JavaScript served by Dockerized Nginx with same-origin API; Mailpit reverse proxy remains an optional fallback.
Authentication policy: verified two-step signup, password login, email OTP, rotating JWT refresh tokens and server-side RBAC.
Support chat policy: authenticated spectator/support conversations, direct-SQL persistence, unread tracking, agent replies and open/closed status.
Support chat UI policy: circular viewport-stable launcher with a stronger transform-only spring drag; closing the panel preserves launcher position, focus and page scroll.
Support reply UI policy: sent agent replies render immediately in the open thread and are reconciled with the server without rebuilding the dashboard.
Language policy: a persistent FA/EN switch beside the theme control translates static and dynamic UI, updates metadata, changes RTL/LTR direction, and is included in the Dockerized frontend image.
Mobile UI policy: compact header controls keep brand, language, theme, sign-in and menu visible without overlap.
County and wallet input policy: county controls are keyboard-searchable; wallet top-up accepts manually entered Persian/English digits and separators.
Email policy: Gmail SMTP is the default real OTP provider; credentials are created locally with configure_gmail.py, and Mailpit remains an optional /mailpit/ fallback.
