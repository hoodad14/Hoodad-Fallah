# ArenaPass Frontend Geography & Typography Update

- Added **485 county-level entries** grouped under all 31 provinces.
- The original database IDs 1..20 remain unchanged, so existing venues, teams and demo users keep working.
- Registration, profile and ticket search use the same grouped county list.
- Date filters are stacked vertically inside the sidebar and cannot overflow.
- The user-provided **Tanha FD** webfont is used site-wide.
- Futsal is removed and filtered from all frontend sport lists, quick cards, matches and ticket views.

Data basis: `sajaddp/list-of-cities-in-Iran` county dataset (official divisions through 1402), supplemented with the verified 1403 additions ترکمانچای، عشق‌آباد و میمه و وزوان. Public sources disagree on the headline total, so the project intentionally favors inclusion to avoid omitting a named county.
