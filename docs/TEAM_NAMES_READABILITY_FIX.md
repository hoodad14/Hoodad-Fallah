# Team names readability fix

Updated the latest frontend to keep long team names readable in ticket cards.

Changes:
- Replaced the team row flex layout with a balanced three-column grid.
- Allowed each team name to use up to two readable lines.
- Added automatic font scaling for long and very long names.
- Increased the blue card-header height and moved the availability badge accordingly.
- Added full team names as hover tooltips.
- Added English-specific typography and narrow-mobile adjustments.
- Prevented long tournament titles from pushing the team row out of alignment.
